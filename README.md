# TradingAgent

繁體中文外匯模擬交易與監控系統。**沒有串接實盤券商，沒有真實資金送單。**

## 目前結果

共研究 608 組標的／週期／參數。EUR/USD 的固定 4 小時策略在獨立測試資料（2025-03-17 至 2026-10-02）有 25 筆自然平倉交易、19 筆獲利，勝率 76%，扣除模型成本後淨利 US$8.62。開發期淨損 US$20.39、驗證期淨損 US$16.98；成本加倍後独立測試淨損 US$0.53。GBP/USD 的額外 168 組策略也未通過前期驗證。

**目前交易閘門關閉，沒有下單。** 25 筆未達事前訂定的 30 筆門檻，而且前期沒有正向淨利。沒有修改門檻、隱藏失敗試驗，或依照最終資料重選參數。模擬初始資金為 US$100,000，回測獲利不會加入模擬帳戶。

完整來源、價格資料、SHA-256、候選策略、失敗試驗、保留測試收據與結果位於 `data/`、`artifacts/`。

## 1% 規則的實作

只購買全額付款的 EUR，不借款、不放空、不使用槓桿。每筆實際買入金額不超過**入場時帳戶權益的 0.8%**，所有最壞退出費用亦須預先納入，全部損失必須小於 1%。即使貨幣價格變成零或程式中斷，已投入本金加費用仍受預算約束。每次僅容許一個部位。

這是**相對入場資金的損失上限**。浮盈高點到低點的回撤、累積多筆交易的帳戶回撤是不同量，會另外記錄；不能宣稱任何市場路徑下的浮盈高點回撤也有絕對 1% 保證。現金外匯帳戶與槓桿期貨／CFD 是不同產品。

成本模型：2 pip 完整價差、每邊 0.2 pip 滑價、每邊 0.35 bps 佣金，最低 US$0.10。價差與滑價已包含在成交價格，佣金分別記錄，沒有重複扣款。全額付款的貨幣餘額沒有借款融資費。這些是公開指示價上的模擬假設，沒有宣稱取得可成交券商報價。

## 執行

Python 3.12，執行與測試只使用標準函式庫，無額外套件：

```bash
cd /workspace/TradingAgent
python -m unittest discover -s tests -v
python -m trading_agent.cli paper-tick --state-dir state --web-dir web
python -m trading_agent.cli serve --web-dir web --port 8000
```

`paper-tick` 取得 Yahoo EURUSD=X 的已完成小時行情、計算同一份策略、處理現有部位並產生監控快照。`serve` 是本機開發用；不是公開網站。`run --interval 300` 可在自行管理的常駐主機執行，但雲端開發工作區不保證程序在任務結束後繼續運作。

## 持續監控與網址

GitHub Actions 在 `main` 推送及排程時執行。`paper-state` 分支保存完整帳戶、交易與 `state/MONITOR.md`，每次以 API 取得實際監控頁面的網址，列於執行摘要。網頁版由 `web/index.html`、`styles.css`、`app.js`、`snapshot.json` 組成，可用 GitHub Pages 發佈。

若 Pages 尚未啟用，在儲存庫 Settings → Pages 將來源設為 GitHub Actions。啟用後可設定儲存庫變數 `PAGES_ENABLED=true`，或手動執行工作流程並勾選 `publish_pages`。程式不會變更儲存庫公開／私人設定，也不會要求憑證值寫入聊天或原始碼。

GitHub 排程可能延遲或被略過。過期報價、無效 K 線、超過入場時窗或回測閘門未通過，均禁止新倉。模擬盤按實際觀察到的報價成交，不回補離線期間假想的成交；回測盤中 OHLC 停損與定時觀察仍有差異。公開儲存庫排程亦可能因長期無活動而被停用，須留意 GitHub 的執行紀錄。

## 回測稽核

`strategy.py`、`risk.py`、`execution.py` 同時供回測及模擬交易使用。訊號只用已完成 K 線，最早下一時段進場；跳空按觀察到的開盤價處理；同一根 K 線同時觸碰停損及目標，優先停損。收尾強制平倉計入損益，勝率只用自然平倉交易。

舊資料的原始券商與時區未確認，只作研究；新的 Yahoo 小時資料有來源、時間與完整性檢查。原生 Yahoo 日線有價格欄位異常，沒有用於最終驗證。策略研究未依最終資料調參，但重複使用開發／驗證資料仍有選擇偏誤，所有試驗均揭露。回測結果不是未來獲利保證。
